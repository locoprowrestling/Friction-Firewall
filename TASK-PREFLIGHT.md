# Task preflight

Copy this file into a task, ticket, or work log and complete it before non-trivial work begins.

```text
Friction Firewall:
- Ask:
- Read first:
- Protected assets:
- Destructive or live risk:
- Backup/rollback:
- Estimate:
- Next action:
```

Verification after the work:

```text
- Artifact inspected:
- Check performed:
- Result:
- Approval/readback, if required:
```
